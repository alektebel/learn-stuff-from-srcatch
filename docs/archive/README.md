# Archive

Session reports from earlier work on this repository, kept for history and moved out of
the root.

These are **not documentation**. They are completion reports written in the first person
about work that was done — "18 Files Created", "All projects meet these criteria!",
"Mission Accomplished" — which is a different genre from the material in the directories
they describe, and a different register from [`PHILOSOPHY.md`](../../PHILOSOPHY.md).

They are also going stale, which is the reason they are here rather than in the root:
